# Алгоритм оценки уникальности машины

## Принцип

ИИ **не выставляет финальный балл**. ИИ классифицирует машину по
каждому критерию (возвращает категорию/тег в JSON), а бэкенд по
фиксированной таблице весов превращает категории в баллы и считает
итоговый score. Это убирает зависимость оценки от "настроения"
модели — один и тот же автомобиль в одинаковом контексте всегда
получит одинаковый балл.

Локальная редкость внутри базы гаражей (кто первый сфоткал редкую
модель) — не считается на этом этапе, отложена на будущее.

Итоговая шкала: **0-100**.

## Критерии и веса

| Критерий | Макс. баллов |
|---|---|
| Тираж/количество выпущенных экземпляров | 20 |
| Год выпуска / возраст (олдтаймер-статус) | 15 |
| Спецсерия/лимитированный выпуск | 15 |
| Комплектация/трим-уровень | 10 |
| Тюнинг/модификации от заводского вида | 10 |
| Цвет (редкость для конкретной модели) | 10 |
| Распространение на данной территории | 10 |
| Тип силового агрегата | 5 |
| Праворульность/нетипичная для региона конфигурация | 3 |
| Состояние/сохранность | 2 |
| **Итого** | **100** |

Марка и модель отдельных баллов не дают — это идентифицирующие
поля, на основе которых ИИ и оценивает остальные критерии (тираж,
распространение, комплектацию и т.д.).

## Таблица категорий → баллы

### Тираж/количество выпущенных экземпляров (max 20)
- `mass` — массовый выпуск (сотни тысяч+): 0
- `medium` — средний тираж (десятки тысяч): 8
- `low` — малый тираж (тысячи): 14
- `very_low` — единичные экземпляры/сотни: 20

### Год выпуска / возраст (max 15)
- `new` — текущий модельный цикл, младше 10 лет: 0
- `mid_age` — 10-25 лет: 5
- `classic` — старше 25 лет (олдтаймер): 15

### Спецсерия/лимитированный выпуск (max 15)
- `standard` — обычная серийная версия: 0
- `special_edition` — юбилейная/лимитированная/спецверсия: 15

### Комплектация/трим-уровень (max 10)
- `base` — базовая комплектация: 0
- `mid` — средняя комплектация: 4
- `top` — топовая/спортивная версия (M, AMG, RS, Type R и т.п.): 10

### Тюнинг/модификации (max 10)
- `none` — заводской вид: 0
- `light` — лёгкий тюнинг (диски, окрас, свет): 4
- `heavy` — серьёзный тюнинг/индивидуальный проект: 10

### Цвет (max 10)
- `common` — стандартный цвет (чёрный/белый/серый/серебристый): 0
- `uncommon` — не самый частый цвет: 5
- `rare` — редкий для этой модели цвет: 10

### Распространение на данной территории (max 10)
- `common` — часто встречается в регионе: 0
- `occasional` — изредка встречается: 5
- `rare` — практически не встречается в регионе: 10

### Тип силового агрегата (max 5)
- `ice` — двигатель внутреннего сгорания, типичный для рынка: 0
- `hybrid` — гибрид: 3
- `electric` — электро (редкость на локальном рынке): 5

### Праворульность/нетипичная конфигурация (max 3)
- `standard` — типичная для региона конфигурация: 0
- `atypical` — нетипичная (например RHD в леворульной стране): 3

### Состояние/сохранность (max 2)
- `average_or_worse` — среднее состояние и хуже: 0
- `excellent` — отличное состояние, оригинал: 2

## Формат ответа от ИИ (JSON)

Модель получает фото + контекст региона пользователя (город из
профиля) и возвращает:

```json
{
  "make": "Toyota",
  "model": "Supra",
  "year": 1998,
  "color_name": "Renaissance Red",
  "fun_fact": "Краткая история/интересный факт про эту модель или экземпляр",
  "criteria": {
    "production_volume": "low",
    "age_category": "mid_age",
    "special_edition": "standard",
    "trim_level": "top",
    "modifications": "light",
    "color_rarity": "uncommon",
    "region_prevalence": "rare",
    "powertrain": "ice",
    "steering_config": "standard",
    "condition": "excellent"
  }
}
```

Бэкенд валидирует, что каждое значение входит в допустимый набор
категорий, маппит их на баллы по таблице выше и считает
`uniqueness_score = сумма баллов по всем критериям` (0-100).

## Fun-fact — отдельный фоновый запрос

`fun_fact` не входит в основной ответ ИИ и не входит в сообщение
бота пользователю. Генерируется отдельным фоновым запросом сразу
после основного анализа, привязывается к той же карточке машины в
БД. Пользователь видит его только при открытии карточки в Mini App —
если фон ещё не успел сгенерировать факт к моменту открытия, Mini
App должна показать плейсхолдер/лоадер и подтянуть его позже.

Основной JSON-ответ ИИ (марка/модель/год/критерии) идёт без
`fun_fact` — это ускоряет и удешевляет первый ответ пользователю в
чате.

## Открытые вопросы

- `region_prevalence` требует передавать модели контекст региона
  пользователя (город из профиля) прямо в промпте — без этого ИИ
  не сможет оценить распространённость на территории
