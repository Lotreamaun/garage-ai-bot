# backend

Сервис бота + API (см. `docs/plan.md`, раздел "Стек" и "Этап 1/2").

Отвечает за:
- Telegram-бота (приём фото, команды `/start`, "мой гараж")
- Обращение к vision-модели (GigaChat / Gemini) и расчёт уникальности
  по алгоритму из `docs/uniqueness-algorithm.md`
- Хранение карточек машин в БД и фото в объектном хранилище
- API для Mini App

Код появится на Этапе 1.
