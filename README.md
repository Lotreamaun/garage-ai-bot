# garage-ai-bot

Telegram-бот + Mini App: фотографируешь машину — ИИ определяет
марку/модель/год и считает оценку уникальности (0-100) по
фиксированному алгоритму, карточка машины сохраняется в твой
личный "гараж".

Пет-проект для себя и друзей, некоммерческий.

## Структура проекта

- [`docs/`](./docs) — документация: план разработки, алгоритм оценки уникальности
- [`backend/`](./backend) — бот (Telegraf) + API + интеграция с vision-моделью + БД
- [`miniapp/`](./miniapp) — Telegram Mini App (фронтенд "гаража")
